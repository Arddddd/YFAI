六口径分层 · 防口径混用的权威对照

⚠ 背景：OpenRouter 样本周支出仅 ~$3B/年，与利润池 $1,000B 差 300 倍——这不是样本差，而是口径差。以下六口径度量价值链不同环节，不可直接对比。

#口径2026 量级定义环节
①利润池口径~$1,000B最终端用户为 AI 产品/服务支付的总收入（不含 Capex）需求侧·终端用户总支出
②GMF 供给侧实收~$160B供给侧已实现货币化营收（模型厂 API+订阅 + 云厂 AI 实收）供给侧·真实货币化

④OpenRouter 样本~$3B平台付费 token × 单价的支出代理API 层·单平台样本
⑤全市场 LLM API~$16B全市场 API token 总量 × 单价API 层·全市场
⑥企业 Foundation API~$12.5B企业付给模型厂的 API 费用API 层·企业
⚠ 跨期比较只用环比/同比，不比水平值（v0.23 新增）：② 与 ⑥、④ 与 ⑤ 各为同一口径对；而 OpenRouter 样本行的历史"水平值"不可跨拉取日比较——货币支出 = 付费 token × 混合单价，混合单价随价格表每次重拉而变（W35 $67.7M→$60.0M、W36 $94.9M→$86.3M，token 量未动）。本表数字为本期（2026-09-27）拉取口径。

正确的关系链——最终端用户的钱大部分停在应用/产品层，只有少部分穿透到模型 API：

① 利润池 $1,000B（终端用户总支出）
   ↓ 只有部分穿透到 API
⑥ 企业 Foundation API $12.5B（模型层收入）
   ↓ 乘以全市场倍数
⑤ 全市场 LLM API $16B（含消费/开发者）
   ↓ OpenRouter 占 ~1/5 全市场 API 支出
④ OpenRouter 样本 $3B（单平台，偏开源低价）
核心规则：④⑤⑥ 是 ① 的一个小切片（~1/60~1/300），用它算绝对量是错的，用它算增速是对的。用途分工——总量看①、货币化看②、上游投入看③、API 层增速/结构看④、API 绝对规模看⑤。

核心逻辑：三速对比 = 长鞭效应 + 环节流速差异 + 平台层自我膨胀

由于产业链传导的长鞭效应和每个环节支出流速（乘数）不同，三个速度的变化（二阶导）存在差异——这是周期划分的出发点。三阶段：Ⅰ 上游增速大幅提升 ＆ 终端服务化支出(buy)小幅提升（gap₁ 扩大）→ Ⅱ 上游放缓 ＆ 终端服务化支出(buy)追赶（gap₁ 收窄，可能有一段齐平）→ Ⅲ 上游进一步放缓 ＆ 终端服务化支出(buy)停止上升。

⚠ 两个 gap + 二阶导判定：gap₁ = 速度B − 平台层（阶段定位主参考）；gap₂ = 平台层 − 速度A（buy）（乐观预期膨胀度量）。终端二次加速（A″>0）时，即使 gap₁ 收窄也不能判阶段切换——可能是第二波长鞭正在形成。

核心判断

模型厂水管的绝对直径决定上游水位。即使企业增速翻倍到50%、乘数从0.06涨到0.12——净增量~$12-15B也不够填补模型厂乘数从0.42→0.20产生的流速缺口~$26B。利润流速切换必然导致上游净支出下降10-20%。SOX翻倍已定价了当前洪流——而未定价的正是流速切换。

⚠ 补充：以上基于「gap₁ 收窄 = 长鞭衰减」解读。若阶段Ⅱ判定终端服务化支出(buy)增速主要来自新场景涌现（内生反馈，A″>0），上游净支出下降幅度可能被低估——需下调阶段Ⅲ的严重程度。且平台层混入乐观预期（OpenAI 占 Azure RPO 45%），真实 gap₁ 比表面读数更接近阶段Ⅱ。

压力侧：中金提示开源模型（尤其中国厂商）凭低价与开放权重形成替代压力、模型端缺可持续差异化壁垒；智堡点出"囚徒困境"——没有哪家公司能承受单方面减速。市场真正的焦点已从"是否放缓"转向 AI 投资 ROI 确定性（美银 7 月调查：45% 基金经理视 AI 泡沫为最大尾部风险，高于 6 月 28%）。

→ 判定（v0.26 更新 · 2026-10-11）：信号 ④「定价行为恶化」本期由「大幅强化」降为「分化」——OpenRouter W40 有效单价回升（1.0343→1.1459·+10.8%，含模型结构上移），但 Ramp 企业实付端仍通缩（anthropic 日频 $0.824/M），两口径分歧。信号 ③「ARR 翻倍节奏衰减」维持观察中，且本期新增一条证据——BTOS 渗透率首次转平（23.8%·+0.0pp，此前 +0.8/+0.6/+0.6）。信号 ①②⑤⑥ 未触发（capex 指引未改、模型发布未停、客户结构无新披露、无新财报）。下一期最直接的验证点：① Ramp 月度是否推进到 9 月数据（当前仍停 8 月、官方文章未发）；② 云 AI 收入 Q3 增速（10 月底）；③ BTOS 转平是否连续第二期。注：用量代理已于 v0.25 由「总量」改为「付费token」；本期 OpenRouter 取 完整周 W40（W41 未完整、不入判断）。

数据源分层原则

数据源分层 = 频率分层 = 质量分层。

下游结论的置信度不能超过其最弱数据层——A 层（财报硬数据）直接决定速度 B / 平台层 / gap₁，其余层只能做边际修正或方向确认，不能推翻 A 层结论。

模型结构缺口（6 条 · 对齐方法论 §4.3）

#缺口为什么重要
1缺少"三速指标的时间序列"需至少 8 个季度历史回填，画出三条曲线才能正式定位阶段——当前三阶段仍是定性框架
2缺少"云内部 AI / 非 AI"拆分四巨头 capex 的 AI 占比是估算（65-70%），实际口径未统一（= GAP⑤）
3缺少价格弹性传导量化token 降价 → 需求弹性（Jevons）的弹性系数无硬数据，目前是定性"量升价跌"
4缺少对 SMH/SOXX 等上游 ETF 的直接映射模型输出的是"上游净支出方向"，尚未映射到具体可交易标的的偏配幅度
5缺少"三速 gap 的机制分解"工具阶段Ⅱ判定需区分长鞭衰减 vs 内生反馈（gap₁/gap₂/A″ 组合），目前为定性判断
6缺少"终端服务化支出"独立度量平台层（Hyperscaler 总营收）混入乐观预期与内部消耗，需 GMF 口径 + AA token 消耗独立度量（= GAP⑥）
